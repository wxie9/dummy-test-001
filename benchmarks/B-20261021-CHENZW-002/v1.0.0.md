## 数据与模型接口

- 数据集：`D-20261021-CHENZW-002@1.1:core`。13 个由发布 seed 生成的 families、共 7,800 个 items；须由上游 `generators/regenerate.py --check` 重建并核验，或从上游评测数据按其许可获取。
- 测试集用途、调参边界和污染检查：评测专用。不得将 items 用于训练、蒸馏、in-context 示例或训练时 prompt；每次运行须记录数据生成/下载路径、release hash 和已知训练污染。
- 模型接口：输入为每 item 的 `state`、固定选项的 typed question；输出每一个选项的概率。typed endpoint 与 chat adapter 的精确输入/解析以 `runner/` 和 `docs/SCHEMA.md` 为准。
- tokenizer revision 与特殊 token：待实际运行时在 EV 记录中固定。
- prompt/system prompt/chat template：decision model 使用 typed endpoint；chat 模型使用上游 runner 的固定 prompt。不得重写题目、选项顺序或 planted detail。
- zero/few-shot 设置：zero-shot；不引入 demonstrations。
- 上下文长度、截断策略、输出解析与后处理：不能完整处理的 item 作为失败/未覆盖项记录；概率必须覆盖所有选项。禁止截断后仍将其作为正常回答计分。

## 执行与计分

- 解码参数：必须记录实际模型、revision、服务端参数、temperature、seed、max tokens、超时与重试；评测器本身不设置虚构默认值。
- 评测框架精确版本/commit 与 task 配置：`src/evaluation/decisionpivot` 的上述提交；数据为 release 1.1 core，记录所有 task-file SHA-256。
- 指标定义：按上游 scorer 报告 item accuracy、contrast-group pair accuracy、level-3 pair accuracy、pair direction、automation at 5% error、accuracy at 0.90 与 calibration error；headline 对 13 families 取平均。
- 重复次数、误差/置信区间处理：若输出随机，固定并记录 seeds；置信区间采用上游 release 的 contrast-group 95% percentile bootstrap（1,000 resamples，seed `20261007`），或在 EV 记录说明偏离。
- 失败/超时/重试：保留每项错误；未覆盖/无效回答不得静默排除。按上游覆盖率规则计分，记录拒答和解析失败。
- 模型裁判：不用。
- 效率比较：不在本协议中比较。
- 结果需要保存：外部存储保存原始 answer JSONL、`_items.json`、scorer 输出和环境；Git 保存 EV 记录与公开摘要。
