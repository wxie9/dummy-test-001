## 数据与模型接口

- 数据集：`D-20261021-CHENZW-004@1.6.0:public`。本协议只覆盖上游公开组成；任何密封题、维护者服务端评测或未公开测试均不在本地复现范围。
- 测试集用途、调参边界和污染检查：公开题只能用于最终评估，不能用于训练、蒸馏、提示选择、阈值选择或测试集驱动的模型选择。每个 EV 记录必须声明模型训练数据与公开题目的已知重叠。
- 模型接口：遵循上游 JevBench 公开 evaluator 所定义的 decision readout；每个选择必须保留完整候选空间与其概率/评分。实际 API、响应 schema、tokenizer revision 和特殊 token 固定到 EV 记录。
- prompt/system prompt/chat template：严格使用固定上游任务配置；若运行需要 adapter，提交前保存 adapter commit/配置，禁止按单个题目修改。
- zero/few-shot 设置：默认 zero-shot；任何示例须来自上游允许的固定配置并在 EV 记录列出。
- 上下文长度、截断策略、输出解析与后处理：不丢题、不删选项。超长、无效格式、拒答、超时和解析失败按上游 evaluator 的失败规则保存和计分。

## 执行与计分

- 解码参数：在 EV 记录保存模型/权重 revision、temperature、top-p、max tokens、seed、停止条件、批大小、并发、超时与重试。
- 评测框架精确版本/commit 与 task 配置：`src/evaluation/jevbench` 的上述提交；每次运行保存其 task/config 文件哈希及公开数据版本清单。
- 指标定义：采用该固定提交中每个公开 task 的官方 metric 和聚合实现；不得将密封集结果、不同版本或自行筛选后的子集混入同一总分。
- 重复次数、误差/置信区间处理：按上游设置；若模型非确定性，记录各 seed 的逐项分数和聚合方式。
- 失败/超时/重试：保留逐项状态、重试次数和最终错误；不得只以成功样本为分母。
- 模型裁判：除非上游 task 明确要求，否则不用；若要求，固定裁判模型、提示和版本并记录复核。
- 效率比较：不在本协议中比较。
- 结果需要保存：外部存储保存公开数据 manifest、原始预测、逐项分数、运行日志与环境；Git 只保存 EV 记录及可公开摘要。
