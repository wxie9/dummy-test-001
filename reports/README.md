# 汇报与图表

- `weekly/YYYY-MM-DD-MEMBER.md`：复制 [周报模板](../templates/weekly-report.md)，关联本周实际交付。
- `milestones/<topic>.md`：阶段总结，说明问题、证据、局限与下一步。
- `figures/`：保存精选训练曲线/评测图表与同名 `.md` 说明，记录输入版本、生成代码/命令、TR-ID/EV-ID 和解释边界。

上述子目录按需创建。大量预测、完整日志和大型产物放外部存储，本目录登记位置。比较模型时列出 checkpoint、数据 split、评测协议版本和实际分母；重要结论链接到原始文献与训练/评测记录。
