# 文献调研

- `searches/<L-ID>.md`：按 [检索模板](../templates/literature-search.md) 保存平台、检索式、时间、筛选和覆盖限制。
- `notes/<citation-key>.md`：按 [文献笔记模板](../templates/literature-note.md) 保存证据、原文位置与项目关联。
- `syntheses/<topic>.md`：跨文献综合，链接笔记并区分共识、冲突和我们的推断；需要时创建目录。
- [references.bib](references.bib)：共享参考文献，引用键与笔记文件名一致。指定维护者负责整库导出。

PDF 保存在 Zotero 共享库或约定附件存储，本地副本可放 `literature/pdfs/`（Git 忽略）。仅有摘要时标明阅读范围；尚未核实的引文不能写成已验证。
