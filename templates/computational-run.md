# 计算运行记录：待填写名称

- 运行 ID：`R-YYYYMMDD-MEMBER-NNN`
- 负责人：待填写成员代号
- 创建日期：待填写
- 实际开始/结束时间与时区：待填写；未执行写“未执行”
- 状态：planned
- 结果：not-evaluated
- 关联问题/假设、文献、湿实验、样本、Issue 与路径：待填写；无湿实验时说明数据来源
- 本次目的与预设评价标准：待填写

## 执行时的代码与环境

- 代码仓库和执行时 commit：待填写完整 commit hash
- 工作区是否有未提交修改：待填写（clean / dirty）
- 若 dirty，完整代码/配置快照的 URI 与 SHA-256：待填写；clean 时写不适用
- 操作系统、架构、计算资源和相关驱动：待填写
- 语言/软件版本、环境文件及锁定文件路径：待填写
- 实际环境导出/容器摘要及定位：待填写或说明无法完整锁定的限制

代码版本应在运行前确定；不要用后来提交本日志的 commit 替代。

## 输入与参数

- 数据集 ID、精确版本、共享定位、校验和：待填写 `D-…@版本`
- 输入样本列表、筛选/排除与理由：待填写
- 配置文件路径、版本/校验和：待填写
- 参数与随机种子：待填写；算法不涉及随机性时说明
- 上游运行 ID 与路径：待填写或注明不适用
- 本次重跑/比较的运行 ID 与路径：待填写或注明不适用

## 执行命令与日志

- 执行工作目录（仓库相对路径）：待填写
- 完整运行命令：待填写；参数保留，凭据通过环境注入
- 标准输出/错误日志 URI：待填写
- 退出码与运行完成情况：待填写；未运行时不填成功码

## 产物与解释

- 输出文件/清单 URI、版本与 SHA-256：待填写
- 指标与不确定性：待填写
- 图表/报告路径与生成方式：待填写
- 验证命令、实际检查结果与未验证项：待填写
- 与基线或上次运行的差异：待填写
- 结果解释、适用边界、失败原因与下一步：待填写
- 复核人、日期及范围：待填写或“尚未复核”

## 更正记录

待更正时追加日期、作者、原内容、改动、依据及受影响的产物；重跑新建 R-ID，保留本次记录。
