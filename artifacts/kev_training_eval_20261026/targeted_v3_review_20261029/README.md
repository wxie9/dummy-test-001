# Kev 续训 v3：七类方案的审阅包

已生成四类新样题68条情境，共94道子题；保留三类原数据，未启动训练。

| 新生成类别 | 情境数 | 核心修正 |
|---|---:|---|
| 概率 | 12 | 双向条件化、贝叶斯、交并补、比较平局、带符号期望收益；choice/score/noul |
| 信息不足 | 28 | 七种场景各四种信息状态；7条真正无法判断，7条虽缺字段仍可判断 |
| 多跳 | 12 | 最近有权祖先、依赖传播方向、控股链、可用性和权限共同约束 |
| 长政策 | 16 | 11条正赔付、5条拒赔；限额/子限额/免赔额顺序、例外和日期边界 |

原样保留：工具路由900、时间/数值800、提示注入600条训练记录；development/test各保留300条。文件在retained/，与v2中相应记录逐字节一致。

阅读：先看“修正说明.md”，再看“样题与标注依据.md”；可直接解析的候选在new_four_families.review.jsonl。manifest.json记录来源哈希、隔离方案和合并状态，coverage.json记录落盘检查。

**这还不是可直接续训的完整新版本。** 68条是用于检查出题和打标的少量样题；没有把它们直接拼到2300条保留数据后面，以免四个修正类别被稀释。待审阅后再确定扩充量及合并采样权重。所有同源对照题当前统一置于review，未冒充独立dev/test。

设计看过官方hard-v1错误，所以该旧测试集后续只能称已知诊断集。精确文本无重合不等于语义独立。本次没有第二个模型独立审题；检查为作者复核、手工参考值和程序校验。长政策有实质性不同条款，但仍共享一个合同骨架；扩充时须增加合同和场景结构，不能只换数字。

复现：在仓库根目录运行 `python3 tools/build_targeted_v3_review.py`。
