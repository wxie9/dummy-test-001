# 实验检查表（C 层 · REFORMS 派生）

> 结构取自 **REFORMS**（Kapoor, Narayanan 等，*Science Advances* 2024，8 节 32 项，
> 官方 `.docx`：`reforms.cs.princeton.edu`）。下面是**按我们三条线裁剪后的最小集**，
> 不是 REFORMS 原文的逐条复制——正式投稿前请对照官方清单再过一遍。
>
> **规则**：每条要么 `- [x]`，要么 `- [ ] … — 未做原因：xxx`。
> 只留空框且不写原因，`--check` 会失败。

## 1 研究设计

- [ ] 本次实验要回答的问题，一句话写下来了
- [ ] 判读规则（什么结果算支持 / 算否定）在**看到结果之前**就写死了
- [ ] 允许的结果不只有阳性——负结果的处置方式已写明

## 2 计算可复现性

- [ ] 代码 commit / 环境 / 依赖版本已记录
- [ ] 随机种子已固定并记录
- [ ] 原始产物（checkpoint / rollout / CSV）有 SHA-256
- [ ] 从干净目录能重跑（或已记录不能重跑的原因）

## 3 数据质量

- [ ] 数据来源、版本、许可已记录
- [ ] 样本量、缺失率、异常值处理已记录
- [ ] 数据的已知局限已写明（不是"没有局限"）

## 4 数据预处理

- [ ] 预处理步骤对**所有实验条件完全一致**（若不一致，差异已列出）
- [ ] 标准化 / 分箱 / 离散化的口径已写明，且**不因条件而异**
- [ ] 预处理只用训练集的统计量拟合（未用到测试集信息）

## 5 建模

- [ ] 模型结构、参数量、每层已记录（Model Card）
- [ ] 训练超参、停止准则、算力已记录
- [ ] 与基线的比较是**同预处理、同预算**下的

## 6 数据泄露 ⚠️

> 本节是 REFORMS 单独成节的一节，也是我们上周实际踩过的地方。**不要跳过。**

- [ ] 测试集在任何环节都没有参与训练 / 选模 / 调阈值
- [ ] 训练与测试的划分方式已写明（随机 shuffle / 按时间 / 按组），且**符合任务语义**
- [ ] 检查过训练集与测试集的重叠（重复样本、同一实体跨集）
- [ ] 新增的输入特征**不含目标的函数**，也不含只有事后才可得的信息
- [ ] 若某特征带来了异常大的提升（如 ≥5 个点），**已专门做过泄露排查**并记录结论
- [ ] 时间序列：支持集/上下文的选取严格因果，未读取预测目标或与之重叠的窗口

## 7 指标与不确定性

- [ ] 主指标在跑之前就定了，且只有一个
- [ ] 报告了离散度（seed 间的原始值，不只是均值）
- [ ] seed 数 < 5 时，**同时报原始点**，不用正态近似造窄区间
- [ ] 指标名称与实际计算一致（例：Spearman 不能标成 Pearson）
- [ ] 配对比较用的是同一组条件（同 seed / 同初始状态 / 同策略顺序）

## 8 泛化性

- [ ] 明确写出结论的**作用域**（哪个环境 / 哪个数据分布 / 哪个表示下成立）
- [ ] 有至少一个分布外或规模外推的检查（或说明为何做不了）
- [ ] 没有把单环境 / 单数据集的结果表述成普遍结论
