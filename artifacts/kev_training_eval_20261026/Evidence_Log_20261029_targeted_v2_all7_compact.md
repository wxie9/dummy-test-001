## 2. 阻塞与风险

- 收益只集中在少数行为上。Qwen3 在六个 suite 中有四个下降；Qwen3.5 也有四个下降。不能把本次续训描述为整体质量提升。
- 这不是纯粹的定向数据实验：`replay=6000` 让定向数据与旧训练数据混合。它会减轻遗忘，但也稀释定向训练信号；即便如此，部分通用能力仍下降。
- 冻结 test 的真实错误类型参与了诊断和合成数据设计。虽然数据与测试题没有精确重合，这次 test 比较仍属于诊断性证据，不是独立留出泛化证明。后续应在 development 或新的留出类别上选择数据、配比和 checkpoint，最后只对冻结 test 做一次比较。
- A800 会在 SSH 会话结束后清理普通后台子进程。训练和评测必须维持在前台 SSH 会话中直到完成。这是服务器运行约束，不是模型结果。

### 真实冻结题的配对例子

- 概率：checkout 需要四个独立步骤成功，成功率为 75%、95%、99%、97%。正确失败率约 31.6%，应选 30%–50%。Qwen3 从正确答案改为 50%–70%。
- 不足信息：退货规则按“送达后 45 天”计时，题目只给出下单日和申请退货日，未给送达日。正确答案是“无法判断”。Qwen3 从正确答案改为“接受退货”。
- 多跳：汇报链为 `Omar → Yusuf（Manager）→ Petra（Senior Manager）→ Wen（Director）`。最近且职位足够高的审批人是 Petra。Qwen3 从 Wen 改为正确的 Petra。
- 长政策：Therapy Services 单次限额 $1,500，扣除额 $50，损失 $1,894，正确赔付为 $1,450。Qwen3.5 从 $1,450 改为 $1,500，即找到了限额但漏扣 deductible。

### 当前解释

当前合成数据对“短、明确、稳定的分类线索”有效，例如是否缺少工具参数、是否存在指令替换攻击。它尚未稳定改善以下能力：从规则中找出真正决定结果的变量；组合多步运算；从长文中检索正确条款后再按正确顺序计算。

这只是单 seed 的配对比较。它不能证明某一种数据机制必然导致回退，也不能据此给出 Qwen3.5 在所有任务上更好或更差的结论。

## 4. 下次会议行动

1. 不要从这两个 v2 stage4 checkpoint 再做一次覆盖全部七类的大混合续训。
2. 分开构造并在 development 上选择四个干预：
   - 概率：补事件语义、补集/条件概率、区间/数值映射，以及更接近真实错误的干扰选项；
   - 不足信息：加入相互冲突的证据、缺少决定变量、信息已经充分的对照题；
   - 多跳：加入 3–5 跳、关系方向反转、无关边和条件关系；
   - 长政策：拆开训练“检索适用条款”“判断是否覆盖”“计算金额”，并明确覆盖 deductible 和计算顺序。
3. 先在 development 上比较 replay 比例、LoRA 学习率和定向数据混合配比；冻结 test 仅保留一次最终比较。
4. 长政策实验必须分别报告资格判断和金额计算；只看总分会掩盖“资格提升、金额下降”的问题。
