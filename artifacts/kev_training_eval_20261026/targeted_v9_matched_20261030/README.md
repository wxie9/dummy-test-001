# Kev v9 完整续训数据

本版有 1500 道基础情境，合计 2300 个子问题。基础情境按可见题面去重；同类仍共用生成规则，不能称为统计独立的 1500 种题型。

| 类别 | 基础情境 | 额外配对视图 | 处理 |
|---|---:|---:|---|
| 概率 | 350 | 350 | 重新生成 |
| 多跳 | 270 | 90 | 重新生成；依赖传播增加配对 |
| 信息不足 | 280 | 280 | 重新生成 |
| 长政策 | 300 | 300 | 重新生成 |
| 工具路由 | 100 | 0 | 保留原文件逐行内容 |
| 时间 | 100 | 0 | 保留原文件逐行内容 |
| 注入 | 100 | 0 | 保留原文件逐行内容 |
| 合计 | 1500 | 1020 | |

`train_base.jsonl` 是 1500 道基础情境。`train.jsonl` 加上 1020 条配对视图，共 2520 条记录、3990 个子问题。1020 条不计作独立的新基础题。训练另混入原先固定的 6000 条回放，总计 8520 条记录、11416 个子问题；这些子问题数均是随机增强前的数量。

配对视图固定问题和候选集合，改变决定性事实，或改变不应影响答案的事实。不是每对都应翻转标签。政策覆盖正赔付、合规但损失不超过免赔额、各种拒赔条件；所有金额选择题均保留 0 候选。依赖题按实际查询距离覆盖 2–5 跳。信息不足题同时包含缺失信息决定结论、缺失信息不影响结论的情况。概率保留不同条件方向、基准率、独立事件和期望计算。

生成时从可见题面复算标签，训练数据 13449 次错误标签替换、开发数据 2744 次替换均被校验器拒绝。校验器由同一作者编写，不能代替独立审查。新题面排除旧版本及官方测试题的规范化文本重复，不代表排除了所有语义同构情境。

配对选择题的 one-hot target 使增强只置换候选，不再增删这些问题的候选。每条记录独立随机置换，因此训练中两视图不保证候选排列相同。没有新增显式配对一致性损失。内容、样本曝光次数和增强方式一起变化，不能把后续差异单独归因于某一项。

Qwen3-0.6B 和 Qwen3.5-0.8B 均从各自定向续训前的原 stage3 初始化，LoRA rank 16，学习率 1e-5，1 epoch，batch 4、accum 2、seed 101，预期 1065 个优化步骤。不是从 v8 或其他定向模型继续累加。

开发数据有 344 道基础情境和 218 条额外视图。政策保留部分领域/保障数/金额尺度组合供开发，依赖图开发增加侧分支；其余类别使用相同生成规则的新实例。训练前后均测完整训练集、开发集及固定探针；训练后测完整 hard-v1 和 devtools-v1，再逐类对比原 stage3 的真实错题修复和新增错误。官方诊断题已影响数据设计，结果不能称为盲测。

模型进程与最近核验时间见 `run_status.json`；数据准备完成不代表训练完成，更不代表七类均已提升。
