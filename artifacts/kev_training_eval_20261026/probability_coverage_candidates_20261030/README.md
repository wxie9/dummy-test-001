# 概率数值覆盖候选

这是下一版完整数据中的概率替换组件：350个训练情境、720个子题；另有60个开发情境、124个子题。尚未并入完整1500题，也未启动训练。其他六类不在此目录，不能把这350题当成全部续训数据。

现有v5的50道“至少一次失败”题，答案概率中位数85.41%，低于30%的只有1道；已用于诊断的评测中对应7个情境有4个低于30%。原训练项目收益绝对值最高625美元，诊断评测最高890,000美元。覆盖差异是可检查的事实，但不能由此断言它导致了退步：Qwen3在低概率8个子题上4→3，在中概率6个子题上5→3；Qwen3.5低概率反而3→4。

候选按固定六个区间覆盖精确概率：0–10%、10–30%、30–50%、50–70%、70–90%、90–100%；低端包含、除最后区间外高端不包含。贝叶斯60题每区间10题；独立事件三种问法按区间分配，其中“至少一次失败”低于30%的有18/50。独立事件同时监督精确数值和概率区间，避免只学高低倾向。

条件频数表和期望收益采用1、10、100、1000、10000五档量级，保持数学规则与成本扣除语义；候选最高收益绝对值6,250,000美元。它覆盖更宽范围，没有逐项照搬诊断集参数或按测试题挑答案。

所有标签依据可见题面复算，844个错误标签突变均被拒绝。训练/开发与冻结测试题面的标准化精确重复为0；这不排除模板相似。Qwen3和Qwen3.5实际分词器预检全部通过，0条过滤。开发题与训练题共用生成器，不是独立泛化证据。

文件：`train.candidate.jsonl`、`development.candidate.jsonl`、`manifest.json`、`coverage_audit.json`、`tokenization_preflight.json`。生成与复算程序为 `tools/build_kev_probability_coverage_candidate.py`；覆盖审计为 `tools/audit_kev_probability_coverage.py`。当前三轮控制及一轮增强保护对照继续运行，见对应目录的 `run_status.json`。
