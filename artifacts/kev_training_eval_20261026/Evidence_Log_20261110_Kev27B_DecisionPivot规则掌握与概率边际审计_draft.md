### 1.1 完成7,800题逐题概率审计

本次分析对象为 Kev-27B custom-v2-style 融合版：

`0.85 × full SFT + 0.15 × local v1`

评测集为 DecisionPivot Core 1.1，共7,800题、13个任务族。没有重新推理；本次直接读取既有评测归档中的各选项概率，再把每道题分为以下六种状态：

| 状态 | 判定规则 | 用途 |
|---|---|---|
| 稳定正确 | 答对，且top1与第二名概率差≥0.50 | 模型明确偏向正确答案 |
| 中等正确 | 答对，且概率差为0.10–0.50 | 答案正确，但把握一般 |
| 脆弱正确 | 答对，且概率差<0.10 | 有“蒙对风险”，但不能证明模型纯猜 |
| 近失误 | 答错，gold排第二，且与top1差<0.10 | 模型确实只差一点 |
| 高置信错误 | 答错，且`pmax≥0.80`、`p_gold≤0.20` | 更像规则、模式或默认策略错误 |
| 其他不确定错误 | 不属于上述错误状态 | 可能是候选混淆或中等强度误判 |

机会水平按每题选项数计算：二选一为50%，六选一约16.7%。细类准确率不高于平均机会水平5个百分点时，标为“基本未学会”。这些都是诊断阈值，不是对模型内部推理过程的直接证明。

### 1.2 总体结果：多数错误不是“只差一点”，多数正确也不是“靠蒙”

Kev融合版答对5,547题，答错2,253题。

| 状态 | 题数 | 相对分母占比 |
|---|---:|---:|
| 稳定正确 | 4,345 | 正确题的78.33% |
| 中等正确 | 977 | 正确题的17.61% |
| 脆弱正确 | 225 | 正确题的4.06% |
| 近失误 | 196 | 错题的8.70% |
| 其他不确定错误 | 1,268 | 错题的56.28% |
| 高置信错误 | 789 | 错题的35.02% |

这组结果支持三个判断：

1. 正确题中只有4.06%属于低边际正确，因此不能把整体准确率解释成“大部分靠蒙”。
2. 错题中只有8.70%是真正的近失误，因此不能把主要问题解释成“概率校准一下就能修好”。
3. 35.02%的错误属于高置信错误。这部分更像模型执行了错误规则、漏掉决定性条件，或形成了错误的默认答案方向。

阈值放宽后结论不变：

- 正确题中，margin<0.05/0.10/0.20的比例为1.84%/4.06%/8.26%；
- 错题中，gold排第二且gap<0.05/0.10/0.20的比例为4.17%/8.70%/17.49%；
- 错题中，`pmax≥0.70/0.80/0.90`且`p_gold≤0.20`的题数为855/789/438。

## 2. Blockers

1. **概率边际不能直接证明内部推理过程。** 低margin只能说明答案容易翻转，不能证明“纯猜”；高置信错误支持存在稳定错误模式，但不能单独证明是哪一批训练数据造成的。
2. **当前只有一次评测前向。** 尚未对低margin正确题做等价改写、不同选项顺序或重复推理，因此“蒙对风险”仍是风险标签，不是最终裁决。
3. **45个细分类相互重叠。** 细类共有4,810个非互斥题目成员，各行题数和错误数不能相加成总体结果。
4. **概率精度有限。** Kev归档概率约保留四位小数。极小差值适合识别边界题，但不应把第四位小数解释成稳定的模型能力差异。
5. **概率未经独立校准。** 温度缩放可能改变概率大小，但不会自动修复默认no、默认yes或候选定位错误。
6. **本轮是定向诊断，不是盲测泛化证明。** 45类来自既有DecisionPivot弱点分析，结论用于设计下一轮训练，不应当作新的独立benchmark成绩。

## 3. Decisions / Learnings

1. **不能用“都是差一点”解释当前DecisionPivot错误。** 严格近失误只占错题8.70%，而高置信错误占35.02%。
2. **不能用“大多数答对是蒙的”否定当前模型。** 78.33%的正确题margin至少0.50，低于0.10的只有4.06%。
3. **依赖、排期和筛选的首要问题是答案方向偏置。** 它们需要平衡的正负反事实对，尤其要增加合法正例，而不是只增加更多同模板样本。
4. **多表事实和部分状态判断存在反向的默认yes问题。** 需要增加“看似满足但缺一个决定条件”的负例。
5. **账本与记录字段首先是候选定位问题。** 训练时应监督逐候选核对过程和最终指针，而不是只监督最后一个选项。
6. **日志与派生字段更像边界不稳。** 这部分适合用边界值、非边界值、等价改写和答案顺序扰动来增强稳定性。
7. **后续评测不能只报准确率。** 至少同时报告脆弱正确率、近失误率和高置信错误率。准确率提高但高置信错误增加，不能视为纯提升。

## 4. Next Meeting — New Actions

1. **先做低margin稳定性复测。** 对225道脆弱正确题生成不改变答案的等价改写，并改变选项顺序；统计答案保持率和margin变化，确认哪些确实是偶然命中。
2. **为依赖、排期和筛选生成最小反事实对。** 每对题只改变一条决定性条件，让答案在yes/no间翻转；正负样本必须平衡，并由程序求解器验证。
3. **为多表事实和状态目标补“缺一条件”的负例。** 重点修复默认yes、数量条件和目标对象漏检。
4. **为账本和记录规则增加候选级监督。** 每个候选先输出是否满足规则及证据字段，再选择最终错误条目；单独评估候选排序准确率。
5. **修复并重建日志差1条数据。** 现有生成器训练的是普通计数选择题，没有覆盖“声明与实际计数差1”的二元核验。修复后先在独立development上确认迁移，再进入全量训练。
6. **下一轮保留四组指标。** 报告accuracy、fragile-correct rate、near-miss rate和confident-wrong rate，并按答案方向拆分yes/no准确率。
7. **完成干预后做逐题配对比较。** 分别统计原错修复、新增错误、低margin正确转稳定、高置信错误是否下降；不只比较总分。
