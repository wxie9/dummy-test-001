# v5 重复“以上皆非”监督修复对照

两路一轮训练及全部评测已完成，目录名保留 candidate。七类合计Qwen3从512到514/1000，Qwen3.5从551到584/1000；相对原v5分别净增1、5道。多跳相对v5为57到59/125、85到84/125，仍未达到两模型七类全部改善。详见 `七类结果.md`、`与v5一轮对照.md` 和 `run_status.json`。

完整数据仍为1500情境、2055子题，另加6000旧数据回放。从原始stage3开始训练1轮，seed101、lr1e-5、LoRA16、batch4/accum2。Qwen3使用GPU3，Qwen3.5使用GPU4。此前三轮控制继续在GPU1/2运行。

唯一修订是为90道自带“以上皆非”的多跳题设置与原硬标签完全相同的one-hot target。现有训练器会对这些题只打乱选项顺序，跳过插入新的“以上皆非”和相应配对增强。事实、原始问题、答案和选项均不变，原三类保留题未修改。没有合并另外准备的多跳扩展、信息不足多视图或政策选项配对候选。

服务器实际代码按seed101重放全部7500情境的三轮增强：原版分别出现28、25、25条含两个等价正确“以上皆非”选项的监督变体，全部属于定向多跳题；修正版保守检测计数为0。此审计不覆盖所有可能的语义错误。

90题的原硬标签与one-hot target在服务器实际损失实现下，测试logits的损失及梯度最大差均为0。监督目标不变，但增强变体数减少，因此这是增强保护对照，不是训练变体数严格匹配的对照。是否改善实际能力，须等同一批七类评测。
