## 变体规则

- 时间、概率、多跳：复用 0.8B 错题邻域的确定性日期平移、计数/金额缩放、实体替换和题面呈现变换；选项显示顺序打乱，标签键保持一致。
- 工具路由：重排工具顺序、重排或格式化 JSON 工具描述，并改变用户请求的呈现前缀；工具本身与请求内容不变。
- 代码审查与代码变更理解：平移统一 diff 的 hunk 行号；增删代码内容不变。
- 测试稳定性：在测试类名加合成命名空间；测试方法内容不变。
- 提示注入：改变消息呈现包装；原消息内容不变。
- 长政策：替换保险文档的签发机构名称；条款与案情不变。

这些是**局部改写**，尤其代码、提示注入和长政策与原种子文本仍非常接近。标签按不变性规则继承，尚未经过独立语义审核；不得称为独立创造的新题。
